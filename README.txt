PAYMENTS
The payment button is ready for a Stripe, Square, PayPal, or other hosted checkout link.

To connect it:
1. Open index.html in a text editor.
2. Find: data-payment-link=""
3. Paste your checkout URL between the quotation marks.
4. On the same line, replace href="#" with the same checkout URL.

FREE PUBLISHING OPTIONS
You can upload this folder to GitHub Pages, Netlify, or Cloudflare Pages.

IMPORTANT
A website can be hosted for free, but card processors normally charge a fee per successful payment.
